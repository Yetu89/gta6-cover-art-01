Vice Sunset Cover Lab turns any photo on your machine into GTA-style cover art: pick a layout of one, four or nine panels, drop in your own photos, crop and position each one, paint it with a Vice City sunset or neon colour grade, letter it with a bold caption and a neon-script subtitle, and export the finished poster as a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080 — all offline, in the browser, with nothing ever uploaded.

## Run it

```sh
node serve.ts
```
