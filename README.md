Vice Sunset Cover Lab is an offline web app that turns any photo and a caption into cover art in the style of GTA 6 posters: six multi-panel layouts, five Vice City sunset and neon colour grades, bold Anton lettering with a neon-script subtitle and a star heat meter, per-panel crop, pan, zoom and photo adjustments, and one-click PNG export in 1080 × 1080, 1080 × 1350 and 1920 × 1080 — all running from static files in the browser, with photos that never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
